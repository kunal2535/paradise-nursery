# Paradise Nursery Shopping Application

Paradise Nursery is a responsive React shopping cart application for browsing houseplants and managing a cart.

## Features

- Landing page with company information and Get Started button
- 18 houseplants across 3 categories
- Responsive product cards with images, names, descriptions, and prices
- Redux Toolkit cart state
- Add, increase, decrease, and delete cart items
- Dynamic cart count, item totals, quantity totals, and order total
- React Router navigation for Home, Plants, and Cart

## Run locally

```bash
npm install
npm run dev
```
